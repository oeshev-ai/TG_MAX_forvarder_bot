# Telegram↔MAX Forwarder Bot

Двусторонняя синхронизация постов между **парами** каналов:

`Telegram-канал-N ↔ MAX-канал-N`

## Что пересылается

- текст
- фото
- видео / animation
- документы
- аудио / voice
- альбомы (media groups) с debounce
- ссылки share из MAX
- пересланные посты в MAX (`link.message`)
- базовая разметка (bold/italic/ссылки и т.п.) через HTML
- цитаты **Telegram → MAX** (HTML blockquote)
- reply-цитаты MAX → TG (как `<blockquote>`)
- правки постов (edit) в обе стороны
- удаления постов **MAX → Telegram** (по mapping)

Неподдерживаемые типы (стикеры, опросы и т.п.) логируются и пропускаются.

**Ограничение API:** стиль «цитата» из клиента MAX при чтении через Bot API обычно **не приходит** в `markup`, поэтому такие цитаты MAX → TG восстановить нельзя. Обычная разметка (жирный/курсив/ссылки) работает.

Свои же пересланные посты отфильтровываются, чтобы не было цикла TG → MAX → TG.

## Надёжность

- retry с backoff при ошибках API
- фоновая очередь пересылки (до 3 задач параллельно)
- длинные подписи (>1024) уходят отдельным сообщением
- длинный HTML (>4096) режется как plain text без поломки тегов
- mapping сообщений в `data/message_map.json`

## Как связать каналы

Пары хранятся в `data/channel_pairs.json`. В `.env` их писать не нужно: бот подхватывает новую пару сразу, без перезапуска.

1. Добавьте бота **администратором** в Telegram-канал.
2. Добавьте бота в канал MAX с правом писать.
3. Откройте бота в личке Telegram или MAX и нажмите /start.
4. Кнопка канала выдаёт код на 10 минут. Отправьте его боту на другой стороне или откройте ссылку из сообщения.
5. Подтвердите пару. Новые посты сразу идут в обе стороны.

Код одноразовый и привязан к одному каналу. Связать можно только канал, где вы админ. `/channels` показывает пары, `/unlink` снимает связь.

Найденные каналы бот пишет в лог и в `data/discovered_channels.json`.

`CHANNEL_PAIRS` в `.env` необязателен. Если он задан, эти пары один раз добавляются в файл, когда таких каналов там ещё нет.

## Подготовка

1. Создайте бота в Telegram и добавьте его **администратором** каждого Telegram-канала.
2. Создайте бота в MAX и дайте ему право писать в каждый MAX-канал.
3. Скопируйте окружение:

```bash
cp example.env .env
```

Заполните:

| Переменная | Описание |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен Telegram-бота |
| `MAX_BOT_TOKEN` | токен бота MAX |
| `CHANNEL_PAIRS` | необязательный начальный список `tg_id:max_id` через запятую |

Пример начального списка, если пары нужно завести без лички бота:

```env
CHANNEL_PAIRS=-100111:-700001,-100222:-700002,-100333:-700003
```

## Запуск локально

```bash
python -m venv venv
# Windows: venv\Scripts\activate
# Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Тесты

```bash
python -m unittest discover -s tests -p "*test*.py" -v
```

## Запуск в Docker

```bash
docker compose up -d --build
docker compose logs -f bot
```

Остановка: `Ctrl+C` или `docker compose stop` — polling и фоновые задачи завершаются корректно.
